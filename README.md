# 手机厂商企业架构规划案例（mobile-manufacturing-togaf）

> 一份**手机制造行业**的企业架构（Enterprise Architecture, EA）规划完整案例参考，覆盖 TOGAF 四大架构域（业务 / 数据 / 应用 / 技术）+ 战略与实施，并附有一份**可直接驱动 AI 编程落地**的企业架构可视化系统需求与设计方案。

本仓库面向：企业架构师、数字化转型负责人、咨询顾问、以及希望用 **AI 编程（AI Coding）** 快速搭建架构资产可视化平台的技术团队。

## 二、这套案例能帮你做什么

1. **学习 TOGAF 落地**：看一个真实行业（手机制造）如何把战略逐层拆解到业务域 → 业务能力 → 数据对象 → 应用系统 → 技术平台，并以 **LTC（线索到回款）端到端流程** 作为贯穿主线。
2. **拿去改造成自己的 EA 规划**：章节结构、表格字段、可视化图表都是通用模板，替换行业内容即可复用。
3. **直接驱动开发**：第 3 节说明——仅凭 `架构可视化浏览系统_需求与设计方案.md` 这一份文档，就能用 AI 编程工具**端到端生成**整套企业架构可视化浏览系统。

## 三、🤖 用 AI 编程实现「整个企业架构可视化系统」

> **重点**：`架构可视化浏览系统_需求与设计方案.md` 不是一篇泛泛的思路文，而是一份**结构化的、可直接喂给 AI 编程工具的工程蓝图**。它已经把技术栈、逻辑架构、数据库表、API 分组、每个页面的布局与可视化库都定死了。因此，**不需要人工从头写代码**——把这份文档（连同 6 章正文、Excel 附件、已有 `html/` 与 `ea-ltc-demo/` 原型）交给 AI 编程工具，即可让它生成可运行的系统。

### 3.1 为什么它"AI 编程就绪"

设计文档里已经明确写死的内容：

- **技术栈约束**：后端 `Python 3.11+ / Flask / SQLite`；前端 `React 18 + TypeScript + Vite + Shadcn UI + Tailwind CSS`；可视化 `AntV X6 / ECharts / Mermaid`。
- **逻辑架构**：React 前端 → Flask REST API → SQLite 元数据模型 → 原始资料层（Markdown / Excel / HTML 配图）。
- **数据库表清单**：文档表、业务架构表、数据架构表、应用架构表、技术架构表、LTC 映射表、API 表、矩阵表、通用关系边表、版本表。
- **API 分组**：Document / Architecture / LTC / Matrix / Impact / Metadata / Import / Search 八类 API。
- **十大功能模块**：总览、业务架构、数据架构、应用架构、技术架构、LTC 穿透、矩阵分析、影响分析、元数据管理、文档资料——每个模块都配有**页面布局草图 + 树层级 + 右侧展示方式**。
- **可视化映射**：哪类图用 X6、哪类用 ECharts、哪类用 Mermaid、哪类用 Shadcn Table，均逐页指定。

→ 这些信息对 AI 编程工具来说就是"需求规格 + 技术设计"，足以直接生成脚手架与大部分业务代码。

### 3.2 推荐落地流程（四步）

```
第 1 步  资料入库（结构化）
        把 6 章 Markdown + 50+ Excel 附件 → 抽取为 SQLite 元数据
        （业务域/能力、数据域/对象、应用/API、技术组件、LTC 映射、关系边）

第 2 步  后端脚手架（Flask + SQLite）
        按文档八类 API 生成：Document/Architecture/LTC/Matrix/
        Impact/Metadata/Import/Search，配 SQLAlchemy 模型与导入脚本

第 3 步  前端 + 可视化（React + TS + Vite + Shadcn + Tailwind）
        实现十大模块页面；用 X6 画架构图/穿透、ECharts 画知识网络/
        雷达/热力、Mermaid 画流程图、Markdown Viewer 渲染章节

第 4 步  复用既有原型，不要从零造
        html/ 里 76 个 ECharts 原型直接作为图表种子；
        ea-ltc-demo/ 的 LTC 知识图谱原型直接作为"影响分析/知识网络图"模块底座
```

### 3.3 给 AI 编程工具的示例指令（可直接复制）

> 把下面这段作为对话首条消息，并把本仓库作为工作区上下文：

```
请基于仓库内的《架构可视化浏览系统_需求与设计方案.md》以及第0–6章、
附件/ 的 Excel、html/ 与 ea-ltc-demo/ 原型，构建一个企业架构可视化浏览系统：

- 后端：Python 3.11 + Flask + SQLite，按文档的八类 API（Document/
  Architecture/LTC/Matrix/Impact/Metadata/Import/Search）实现 REST 接口；
  编写从 Markdown 与 Excel 抽取架构元数据并写入 SQLite 的导入脚本。
- 前端：React 18 + TypeScript + Vite + Shadcn UI + Tailwind CSS，
  实现文档列出的十大模块页面与左侧树状浏览 + 右侧工作区布局。
- 可视化：AntV X6 画架构图与 LTC 穿透；ECharts 画知识网络图/雷达/热力；
  Mermaid 画流程图；复用 html/ 与 ea-ltc-demo/ 的现有原型作为种子。
- 每完成一个模块，停下来让我确认后再继续。
```

### 3.4 适用工具

| 工具 | 用法 |

## 四、本地查看（无需安装）

- **可视化原型**：直接双击打开 `html/` 下的任意 `.html`（如 `图2-3_业务能力地图.html`），浏览器即可交互。
- **LTC 知识图谱**：进入 `ea-ltc-demo/`，用浏览器打开 `LTC知识网络图.html`；如需重新生成，运行 `python build_ltc_knowledge_graph.py`（需 Python 3.11+）。
- **Excel 附件**：用 Excel / WPS / 在线表格打开 `附件/` 下各 `.xlsx`。
