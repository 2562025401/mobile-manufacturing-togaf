# 业务对象层（Business Object Layer）

> **定位**：三层架构的最底层。企业核心业务能力 = 业务对象行为方法的组合；企业的场景流程 = 业务能力的组装编排。
> **本层交付**：列出全部业务对象（基于第3章数据架构14个数据域L4对象 + MDM主数据清单），每个含 **对象名称 / 对象说明 / 对象行为方法 / 所属业务域**。
> **覆盖范围**：14个业务域（D01-D14），核心价值域（研发/供应链/制造/营销/销售/服务/生态）+ 支撑域（战略/人力/财务/法务/安全/IT/行政），共 102 个业务对象。

## 1. 战略主题（`strategy_theme`）

- **所属业务域**：D01 战略与经营管理
- **数据分类**：规则/参照数据
- **对象说明**：将企业愿景与战略目标转化为可跟踪的战略主题组合，是S2P价值流顶层对象。
- **对象行为方法**：

| # | 行为方法 | 说明 |
|---|---|---|
| 1 | `创建战略主题` | 将战略目标分解为5-8个可量化主题，含优先级与目标值 |
| 2 | `关联战略地图` | 映射到财务-客户-流程-学习成长四层面因果链 |
| 3 | `设定优先级` | 按战略匹配度/收益/可行性排序，冲突由战略委员会裁决 |
| 4 | `季度复盘` | 跟踪KPI达成，偏差>15%触发红牌预警 |
| 5 | `冻结归档` | 主题终止后版本化归档 |

## 2. 战略KPI（`strategy_kpi`）

- **所属业务域**：D01 战略与经营管理
- **数据分类**：规则/参照数据
- **对象说明**：企业级可量化指标体系，连接战略主题与经营结果。
- **对象行为方法**：

| # | 行为方法 | 说明 |
|---|---|---|
| 1 | `定义KPI口径` | 明确计算逻辑、数据源、采集频率、Owner |
| 2 | `设定目标值` | 参考行业75分位基准设定Y0-Y3目标 |
| 3 | `关联战略主题` | 每个流程层KPI至少支撑一个客户层KPI |
| 4 | `变更走ECN` | KPI定义卡片变更须走工程变更流程 |
| 5 | `季度刷新` | 战略地图每季度更新一次 |
