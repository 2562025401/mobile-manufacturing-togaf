# 业务场景流程层（Business Scenario / Process Layer）

> **定位**：三层架构的最上层。**企业的业务场景/流程 = 业务能力的组装编排与组合**（业务对象方法 → 能力 → 场景 的纵向贯通）。
> **本层交付**：列出全部业务场景流程（基于第2章8条端到端价值流 + LTC七阶段 + 旗舰场景 + 支撑链示例），每个说明 **用到的业务能力 / 业务能力的组装方法和步骤**。
> **覆盖范围**：核心价值链（I2L/LTC/P2P/P2M/I2R）+ 支撑链（B2R财务/T2P人力/R2C法务合规安全/D2S IT/R2S行政），全部覆盖。

## 1. VF01 从创意到上市(I2L)

- **所属价值流**：VF01 从创意到上市
- **用到的业务能力（14个）**：

  `用户需求池`、`竞品分析`、`产品机会识别`、`产品路线图`、`产品定义Charter`、`阶段门DCP`、`EBOM管理`、`PBOM/MBOM协同`、`ECN变更管理`、`S&OP协同`、`需求预测`、`成本波动分析`、`本地认证`、`区域品牌策略`

- **业务能力的组装方法和步骤**：

  1. [产品研发.用户需求池]采集用户洞察+[产品研发.竞品分析]对标，聚合为结构化需求池
  2. [产品研发.产品机会识别]评估机会→[产品研发.产品路线图]锁定12-24月路线
  3. [产品研发.产品定义Charter]输出Product Charter(目标成本/卖点/SoC选型)，并经[战略与经营管理.战略主题管理]对齐高端突破主题
  4. [产品研发.阶段门DCP]六阶段门控(研发+供应链+制造+质量+财务+营销+合规共签)
  5. [产品研发.EBOM管理]→[PBOM/MBOM协同]派生制造BOM，[ECN变更管理]闭环变更
  6. [供应链.需求预测]+[S&OP协同]提前26周评估关键物料与供应可行性，[成本波动分析]控目标成本
  7. [法务与合规.本地认证]+[区域品牌策略]完成区域准入与品牌合规，产品可销售

## 2. VF02 从线索到回款(LTC)

- **所属价值流**：VF02 从线索到回款
- **用到的业务能力（27个）**：

  `品牌定位`、`线索采集`、`线索评分`、`MQL移交`、`价格体系`、`促销规则`、`购物车/下单`、`订单审核`、`库存承诺ATP`、`信用额度(应收确认)`、`S&OP协同`、`MRP运算(供应计划)`、`采购订单`、`交期确认`、`主生产计划MPS`、`工单管理`、`SMT执行`、`包装入库`、`仓店路由`、`拣配发货`、`签收确认`、`多渠道报修`、`维修诊断`、`NPS回访`、`应收确认`、`渠道回款`、`返利结算`

- **业务能力的组装方法和步骤**：

  阶段1 市场与商机: [市场营销.线索采集](绑定隐私授权)→[线索评分]→[MQL移交]销售
  阶段2 销售与下单: [价格体系]+[促销规则]校验→[购物车/下单]创建订单→[订单审核]五步审核(价/促/库/信/合)→[库存承诺ATP]可履约确认
  阶段3 计划与供应: [S&OP协同]平衡→[供应计划]+[BOM]MRP运算→[采购订单]+[交期确认]保障物料
  阶段4 生产制造: [主生产计划MPS]→[工单管理]齐套→[SMT执行]→[包装入库]IMEI绑定
  阶段5 物流交付: [仓店路由]选履约节点→[拣配发货]出库→[签收确认]触发应收
  阶段6 客户服务: [多渠道报修]→[维修诊断]→[NPS回访]→质量问题回流CAPA
  阶段7 财务回款: [应收确认]→[渠道回款]核销→[返利结算]完成现金闭环

## 3. VF03 从计划到采购(P2P)

- **所属价值流**：VF03 从计划到采购
- **用到的业务能力（15个）**：

  `需求预测`、`S&OP协同`、`供应计划`、`多级库存策略`、`供应商准入`、`招投标管理`、`框架协议`、`供应商绩效`、`采购申请`、`采购订单`、`交期确认`、`到货协同`、`入库上架`、`应付`、`成本波动分析`

- **业务能力的组装方法和步骤**：

  1. [需求预测]生成SKU-区域-周预测→[S&OP协同]形成供需平衡计划
  2. [供应计划]MRP运算出物料净需求→[多级库存策略]计算安全库存
  3. [供应商准入]→[招投标管理]→[框架协议]确定供应商与商务条款
  4. [采购申请]→[采购订单]→[交期确认]锁定供应
  5. [到货协同]ASN→[入库上架]质检→[应付]三单匹配付款
  6. [供应商绩效]评分反馈→[成本波动分析]控本，闭环优化
